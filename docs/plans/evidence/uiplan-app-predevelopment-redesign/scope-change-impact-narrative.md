# Scope and Change Impact Narrative

## In scope

- UiPlan app planning-first IA and interaction contracts
- Objective pre-coding gates and evidence contracts
- BA/SE/UX sign-off workflow and decision logging

## Out of scope

- Production feature implementation beyond planning contracts
- Runtime business data integrations
- New backend APIs

## Changes by version

- `v1.0 -> v1.1`: added objective gate clauses, traceability contract, scored readiness rubric, governance workflow, IA and interaction contracts.
- `v1.1 -> v1.2`: added fixed persona test scripts, KPI targets, evidence schema template, business-facing required artifacts, tie-break authority.

## Downstream impact

- Tasks now require evidence attachments before Ready/Done acceptance.
- Sign-off accountability is explicit, reducing approval ambiguity.
- Implementation work can be sequenced by verified gates instead of subjective review.
