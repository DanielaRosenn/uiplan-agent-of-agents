# BA -> SE -> Dev Handoff Packet

## Business intent summary

The UiPlan app must lead with planning clarity: business intent, blockers, decisions, and next action before deep metadata.

## Architecture mapping summary

- Story -> ArchitectureElement -> Task -> Evidence contract is mandatory.
- Mode model is fixed: Orient, Decide, Execute, Verify.
- Inspector and rail use priority slots to preserve decision-first reading order.

## Execution checklist

- Confirm target mode behavior and transition rule.
- Confirm task has linked acceptance criteria and evidence placeholder.
- Confirm blocker owner and due date are present.
- Confirm no High/Critical unresolved blockers for Ready state.

## Ambiguity log

- Current status: cleared.
- Rejection loop rule: any ambiguity discovered by Dev returns to BA+SE review with change request entry and updated scope version.
