To capture:
1. Run the orchestrator with a sample brief
2. Start viewer: `cd ui && python -m http.server 8765`
3. Open: http://localhost:8765/copilotkit/viewer.html#tab=uiplan
4. Take screenshot showing the interface
5. Save as `viewer-screenshot.png`
