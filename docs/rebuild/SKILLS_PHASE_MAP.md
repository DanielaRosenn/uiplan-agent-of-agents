# UiPlan Phase-to-Skill Map

## Intake
- `uipath-solution-design` for decomposition from PDD/instructions.
- `uipath-review` for quality/readiness audit before planning.

## Plan
- `uipath-solution-design` for architecture and paradigm selection.
- `writing-uipath-plans` for executable implementation planning.

## Build
- `uipath-rpa` for XAML workflow construction and validation.
- `uipath-maestro-flow` / `uipath-maestro-bpmn` when flow/process surfaces are selected.
- `uipath-agents` for coded agent surfaces.
- `uipath-troubleshoot` for failed analyze/test loops.

## Deploy and test
- `uipath-deployment-readiness` for non-production gating.
- `uipath-platform` for queue/asset/folder/runtime checks.
- `uipath-test` for automated and smoke validation.

## HITL and operations
- `uipath-tasks` for Action Center lifecycle.
- `uipath-interact` for UI-state validation when needed.
- `uipath-governance` for policy-level enforcement.

## Evidence
Every phase emits selected skill identifiers into runtime events for CopilotKit
traceability and post-run review.
